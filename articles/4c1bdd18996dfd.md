# CSV編：行動実験データを処理する

例：`data.csv`
```csv
trial,latency
1,2.3
2,2.7
3,3.1
4,2.5
````

## 平均値を出す

```python
import pandas as pd

df = pd.read_csv("data.csv")
mean_latency = df["latency"].mean()
print("平均反応時間:", mean_latency)
```

出力：

```
平均反応時間: 2.65
```

## グラフ化する

```python
import matplotlib.pyplot as plt

plt.plot(df["trial"], df["latency"], marker="o")
plt.xlabel("Trial")
plt.ylabel("Latency (s)")
plt.title("Reaction Time per Trial")
plt.show()
```

これだけで「試行ごとの反応時間」を視覚化できます。

# ABF編：電気生理データを処理する

パッチクランプなどのデータは `.abf` (Axon Binary File) 形式で保存されます。
Pythonでは [pyABF](https://pypi.org/project/pyabf/) を使います。

## 基本の読み込み

```python
import pyabf

abf = pyabf.ABF("example.abf")
print("サンプリングレート:", abf.dataRate)
print("スイープ数:", abf.sweepCount)
```

## 波形をプロット

```python
import matplotlib.pyplot as plt

abf.setSweep(0)  # 1本目のスイープ
plt.plot(abf.sweepX, abf.sweepY)
plt.xlabel("Time (s)")
plt.ylabel("Current (pA)")
plt.title("Sweep 0")
plt.show()
```

これでClampfitを使わずにPythonだけで波形を可視化できます。

# GitHubでツール集にまとめる

実験ごとに書いたスクリプトをまとめておくと便利です。
ここではリポジトリ `neuro-utils-python` を例にします。

```
neuro-utils-python/
├─ scripts/
│  ├─ csv_average.py
│  ├─ abf_plot.py
└─ README.md
```

`csv_average.py`

```python
import pandas as pd

def calc_average(filename):
    df = pd.read_csv(filename)
    return df.mean()

if __name__ == "__main__":
    print(calc_average("data.csv"))
```

`abf_plot.py`

```python
import pyabf
import matplotlib.pyplot as plt

def plot_abf(filename, sweep=0):
    abf = pyabf.ABF(filename)
    abf.setSweep(sweep)
    plt.plot(abf.sweepX, abf.sweepY)
    plt.xlabel("Time (s)")
    plt.ylabel("Current (pA)")
    plt.title(f"Sweep {sweep}")
    plt.show()

if __name__ == "__main__":
    plot_abf("example.abf")
```

# Spikes and Burstsから学ぶ

電気生理データ解析については、ブログ **[Spikes and Bursts](https://spikesandbursts.wordpress.com/)** が非常に参考になります。

* [Patch Clamp Data Analysis in Python: Bursts](https://spikesandbursts.wordpress.com/2023/08/24/patch-clamp-data-analysis-in-python-bursts/)
  Pythonで活動電位バーストを検出する実例。pyABFを活用した解析のヒントが豊富。

* [Clampfitでのパッチクランプ解析（活動電位編）](https://spikesandbursts.wordpress.com/2022/05/03/patch-clamp-analysis-clampfit-action-potentials/)
  既存ソフトウェアでの解析フローをまとめた記事。Pythonと組み合わせることでより柔軟なワークフローが可能。

こうした知見を参考にしつつ、自分の研究スタイルに合った「ちょっと便利なスクリプト」をGitHubに積み上げていくのが効果的です。
